一、先搞懂几个名词

如果你熟悉无线，跳到第二节。这一节是给不熟的人的。

信道矩阵 H

描述"基站发出的信号，到了终端变成什么样"。每根发射天线到每根接收天线、每个频率点上，都有一个复数表示幅度和相位的变化。所有这些复数摆在一起就是信道矩阵。

RB（资源块）

频率被切成的小格子，每格 12 个子载波。100 MHz 带宽在 30 kHz 子载波间隔下有 273 个 RB。RB 数就是信道在频率方向的分辨率。

CDL / TDL（信道模型）

3GPP 标准里的"多径配方"：信号从基站到终端会走好几条路径，每条晚到多久、多强。CDL 还给出每条路径的来去角度，TDL 不给——这是两者最关键的区别。

PDP（时延功率谱）

把信道从频域变到时延域，看"信号能量分别在什么时刻到达"。反映多径的时间分散程度。

PMI（预编码矩阵指示）

终端告诉基站"你按这个权重发，我收得最好"。从标准码本里挑一个编号回报，省得传整个矩阵。

SRS / RSRP

SRS 是终端发的探测信号，基站靠它测上行信道。RSRP 是收到的参考信号功率，衡量信号强弱。

三、数据长什么样

所有信道数组都遵循同一套维度约定：

N 样本数 T 连续时隙数 RB 资源块（频率） BS_ant 基站天线 UE_ant 终端天线 K 小区数 
ds.h_true          # [N, T, RB, BS_ant, UE_ant]  complex64  理想信道
ds.h_est           # 同形                                    带导频与噪声的估计信道
ds.h_interferers   # [N, K-1, T, RB, BS_ant, UE_ant]        干扰小区信道

一个 [6, 1, 51, 4, 4] 的数据集意思是：6 个样本、每样本 1 个时隙、51 个 RB、基站 4 天线、终端 4 天线。

数据不进对话。单个样本按 273 RB × 64 天线算就有几百 KB，序列化成文本会膨胀到十几 MB。所以 MCP 只返回句柄和一段取货代码，数据落盘、你在自己的 Python 里读。

护栏拦的是"跑得出结果但结果没意义"的组合。比如波束搜索配 TDL——TDL 没有每条径的角度，算法会输出一堆看似正常的数字，不崩溃、不报错、图也画得出来，但结论是假的。这类错误最难查。

§7.8.1 指标2 / §7.8.2 指标2几何量 CDF，含噪与不含噪两条R1-165974 / R1-165975

角度扩展用圆周标准差而非普通标准差： AS = sqrt(−2·ln|Σ P·exp(jφ) / Σ P|)。普通标准差在角度绕回 0/360° 时会算出 荒谬的大值，标准在 §7.8.2 特意写明用 TR 25.996 的圆周定义就是这个原因。

CDL 剖面表已被替换为标准值。ChannelHub 自带的 CDL-A/B/C 三张表 角度列与 38.901 不符（CDL-C 有 23/24 簇有出入，占总功率 93.8%）， superwireless 启动时会用逐字核对过的标准表覆盖。 设 SUPERWIRELESS_CDL_SPEC=0 可复现未修正前的结果。 CDL-D/E 不在覆盖范围内——它们的表结构含 Cluster PAS 列、 首簇拆成镜面与 Laplacian 两行，没有逐字核对过的表宁可不放。

七、能力边界

做得到

· 单小区到 57 小区的统计信道
· 10 个真实城市的射线追踪
· 完整物理量：未归一化 PDP、完整协方差与全部特征值、码本索引 PMI、每天线增益、路损与视距判定
· 干扰小区信道矩阵（不只是 SINR）
· 多时隙时序数据（实测 60 km/h 下首末时隙相关系数 0.346，确实老化）
· 任意 ChannelHub 支持的阵列结构（1驱3 等）

做不到

· 射线追踪的逐径几何——ChannelHub 尚未把 Sionna 的 Paths 对象导出到数据契约
· QuaDRiGa——需要 MATLAB/Octave 运行时
· 直接设定信噪比——它是路损、发射功率、撒点位置的结果
· 用剖面强制视距——视距由几何判定
· 通用接收机链路级仿真（现有表 3 只覆盖经典 MMSE 接收机的 20B NewTx/ReTx BLER 曲线）

有条件的几项

能力条件不满足时
TDD CQI/BF Gain/OLLA 选 MCSCQI 来自 PMI 权；SVD/PMI 使用同一信道、CSI、rank、功率、干扰和经典 MMSE 接收机工况或 rank 不一致时拒绝计算；CQI0 返回不调度
每条径的角度必须用 CDL 模型TDL 下角度字段为 None；射线追踪数据直接报错

下行预编码矩阵视配置而定实测单小区为 None，多小区/多时隙有值。用前判空
时序相关性num_slots_per_sample > 1T=1 时样本间独立，无时序可预测
指定信噪比区间走拒绝采样区间偏离实际分布太远时可能一个样本都取不到，会报错并给出实际分布
射线追踪pip install sionna-rtsw_capabilities 如实报告不可用及缺什么
